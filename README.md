# Intelligent Enterprise System (NEXUS.AI OS)

An AI-powered, modern **Intelligent Enterprise System** built using pure **HTML5, CSS3, and Vanilla JavaScript (ES6)**.

---

## 🌟 Key Features
  
1. **Executive Command Center**:
   - Live KPI cards with trend indicators and sparklines.
   - Interactive Chart.js graphs for ARR Machine Learning Revenue Projections & Enterprise Resource Distribution.
   - Live Anomaly Stream and Autonomous Decision Engine recommendation cards.

2. **Enterprise AI Co-Pilot**:
   - Conversational AI Assistant interface for indexing ERP, CRM, and Financial telemetry.  
   - Natural language query handling and scenario simulations.  
   - One-click Executive AI Briefing Generator.

3. **ERP & Operations Manager**:
   - Interactive Data Table with search, department/status filtering, pagination, and asset addition modal.
   - Health status pills and audit tracking.

4. **CRM Sales Intelligence Pipeline**:
   - Visual 5-Stage Kanban Board (Leads, AI Qualification, Proposal Sent, Negotiation, Closed Won).
   - Predictive AI Win-Scoring per opportunity.

5. **Visual Workflow Automation**:
   - Trigger-Processor-Action flow node visualizer.
   - One-click trigger execution test simulator.
   - Toggle switch controls for operational rules.

6. **Financial Analytics & Risk Radar**:
   - Quarterly Cash Flow breakdown chart.
   - Operational Expenses distribution donut chart.

7. **System Customization & Export**:
   - Dark Mode / Light Mode theme toggle (with local persistence).
   - Instant Executive JSON/CSV report exporter.

---

## 🚀 How to Run

1. Extract `intelligent-enterprise-system.zip`.
2. Double-click `index.html` to launch directly in any modern web browser (Chrome, Edge, Firefox, Safari).
3. No Node.js, Python, or backend server installation required!
